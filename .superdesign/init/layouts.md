# Shared layouts

## `src/components/layout/app-shell.tsx`

Client shell composing the fixed desktop sidebar, mobile navigation, and content column.

## `src/components/layout/sidebar-nav.tsx`

Dark 224px primary navigation with Remindly wordmark, Dashboard/Reminders/Settings links, active route state, and private-workspace owner footer.

## `src/components/layout/mobile-nav.tsx`

Mobile header with wordmark and menu trigger; opens the same sidebar inside a modal navigation panel with focus handling and backdrop close.

## `src/components/layout/page-header.tsx`

Reusable title/description/action header used by Dashboard, Reminders, and Settings.
